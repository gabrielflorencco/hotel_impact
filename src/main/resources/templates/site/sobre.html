Sobre o projeto

Um PMS de hotel construído como deve ser

O HotelImpact é um sistema de gestão hoteleira (PMS — Property Management System) desenvolvido como trabalho acadêmico de engenharia de software. O objetivo é demonstrar, em um domínio real e exigente, como um sistema operacional deve se comportar: regras de negócio aplicadas pelo servidor, integridade garantida pelo banco de dados e uma interface que respeita quem trabalha nela o dia inteiro.

Decisões de engenharia

O projeto é construído em Java 21 com Spring Boot, renderização no servidor via Thymeleaf e persistência em PostgreSQL com Spring Data JDBC. O esquema é inicializado pelo mecanismo nativo do Spring Boot (schema-DB_CREDENTIAL_PLACEHOLDER.sql). As regras que dependem de concorrência — duas reservas sobrepostas no mesmo quarto, duas hospedagens simultâneas, estoque negativo — são reforçadas por constraints específicas do PostgreSQL (exclusão por intervalo, índice único parcial e CHECK), e não apenas por validações da aplicação.

Todo cálculo de dinheiro (totais, saldo devedor, receita) é feito pelo servidor; a interface nunca inventa números. Valores são históricos: a diária acordada na reserva e o preço do consumo no momento do lançamento não mudam quando o catálogo muda.

Qualidade verificável

A suíte de testes cobre validação de formulários (unitário), regras de negócio contra um PostgreSQL real (integração), a camada web com MockMvc e a segurança da autenticação — login, logout, CSRF e proteção de rotas.

Contexto

Este é um projeto acadêmico de desenvolvimento de software. Não há clientes reais, depoimentos ou números de mercado por trás dele — apenas um sistema construído com o rigor que a operação de um hotel exige.
